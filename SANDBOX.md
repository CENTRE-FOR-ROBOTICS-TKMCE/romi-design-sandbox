# design team sandbox

This is the **design** team's experiment/sandbox fork of `CENTRE-FOR-ROBOTICS-TKMCE/romi`.

- Push freely here - branch, break things, iterate.
- When something's stable, open a pull request from a branch in this
  fork into `CENTRE-FOR-ROBOTICS-TKMCE/romi`'s default branch.
- Periodically sync this fork with main (GitHub UI "Sync fork" button,
  or `gh repo sync CENTRE-FOR-ROBOTICS-TKMCE/romi-design-sandbox`) so you're not testing against
  something stale.

Full contribution workflow: see CONTRIBUTING.md in `CENTRE-FOR-ROBOTICS-TKMCE/romi`.
